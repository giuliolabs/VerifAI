# Main User Study - Usability and Trust Evaluation (Week 20)

## Overview
This folder contains materials and results for the **main user study** conducted to
evaluate the usability, trustworthiness, and perceived reliability of the VerifAI
deepfake detection system.

The study follows an initial pilot usability phase and involves approximately
30 participants, in line with standard human–computer interaction practices.

## Objectives
- Measure system usability using the **System Usability Scale (SUS)**
- Assess **user trust and confidence** in AI-assisted deepfake detection
- Evaluate perceived transparency and reliability of model outputs
- Collect anonymized user feedback for qualitative insights

## Methodology
Participants interacted with the VerifAI system by:
1. Uploading or testing videos for deepfake detection
2. Reviewing prediction outputs and explanations
3. Completing a post-task survey

The survey combines:
- Standard SUS questions
- Trust-related metrics adapted from recent literature (e.g. Sippy et al., 2024)

## Ethics and Privacy
- No personally identifiable information (PII) is stored
- Raw survey data is anonymized before analysis
- Participation is voluntary and based on informed consent

## Folder Structure
- `materials/` — consent forms, task sheets, participant information
- `surveys/` — survey templates and anonymized responses
- `analysis/` — scripts and aggregated results

## Status
Data collection and analysis are conducted as part of **Week 20** of the project.
